# 云梦代理佣金规则

## 一、直接用户奖励

成功邀请用户并建立代理关系后,该用户产生的实际消费利润可为代理带来推广佣金。

| 阶段 | 佣金比例 |
|---|---|
| 绑定后 7×24 小时内 | 实际消费**利润**的 **50%** |
| 7×24 小时后至绑定满 1 年 | 实际消费**利润**的 **15%** |
| 绑定满 1 年后 | 不再产生直接推广佣金 |

## 二、下级代理奖励

代理邀请其他用户成为代理后,可获得下级代理产生的团队奖励。

每一级代理可获得其**直属下级代理有效佣金的 5%**。代理层级可继续向下发展,
每一级按照对应层级规则获得团队奖励。

## 三、佣金计算方式

```
代理佣金 = 用户实际消费产生的利润 × 对应佣金比例
```

利润指该笔消费的售价扣除平台采购成本后的部分,由系统自动核算。

**充值金额本身不产生佣金**,只有用户实际产生有效消费后,才会计算对应佣金。

## 四、佣金发放与提现

### 1. 佣金形态

佣金以**平台额度**形式计入代理的「推荐计划」账户,不自动发放为现金。

### 2. 转为消费额度(自助,实时到账)

在控制台「推荐计划」页面可随时将佣金转为账户可用额度,用于抵扣 API 消费。

- 单次最低转换 **¥1**
- 转换后不可撤销

### 3. 提现(人工办理)

佣金**无最低提现门槛**,可随时添加主理人微信申请提现。

- 微信号:*(待补充)*
- 申请时请提供:账号邮箱、提现金额、收款方式
- 一般于 **3 个工作日**内处理完成

## 五、佣金说明

1. 实际消费指用户正常使用平台服务产生的有效消费金额。
2. 退款仅针对账户内**未消费**的余额。未消费的金额不产生佣金,因此退款
   不影响已结算的佣金。
3. 请求失败而退回的预扣额度,不计入有效消费,不产生佣金。
4. 每个用户只能绑定一名直属代理。
5. 代理关系建立后原则上不可更换。
6. 代理不得通过自注册、自消费、虚假账号、批量注册等方式获取异常佣金。
7. 对于异常交易、违规推广或其他影响平台正常运营的行为,平台有权暂停相关
   佣金结算并进行核查,已发放的异常佣金平台有权追回。
8. 本规则最终解释权归云梦 API 所有,如有调整将提前公示。
