## 云梦 API

面向国内开发者的 AI 模型统一接入服务。

### 我们做什么

把 Anthropic、OpenAI、Google、字节跳动的模型汇聚到一个接口地址、一个密钥之下。你不需要海外账号、不需要信用卡、不需要改代码,把 `base_url` 换掉就能用。

### 支持的能力

- **对话** —— Claude Opus 5 / Sonnet 5 / Fable 5、GPT-5.4 ~ 5.6 系列
- **生图** —— GPT Image 2(1K / 4K)、Nano Banana Pro(最高 5504×3072)
- **生视频** —— seedance 系列,480p 至 4K,按秒计费

### 三种协议,同一个密钥

| 协议 | 端点 |
| --- | --- |
| OpenAI 兼容 | `/v1/chat/completions` |
| Claude 原生 | `/v1/messages`(Claude Code 可直接使用) |
| Gemini 原生 | `/v1beta/models/{model}:generateContent` |

### 计费

按 token 实际用量结算,人民币计价,充值多少用多少,**不做赠送、不设有效期**。

缓存命中、缓存写入分别计价,长对话与代码库场景的实际成本显著低于标价。
